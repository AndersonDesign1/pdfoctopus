# PDFoctopus

> Eight arms. Every PDF job.

**Status: 🚧 work in progress.** PDFoctopus is in early development and is not ready to use yet.
See [PHASES.md](./PHASES.md) to follow progress.

---

## What it is

PDFoctopus is a free, open-source, all-in-one PDF tool for everyday work. It will run as a
desktop app (Windows first) and in the web browser.

It edits, signs, fills, locks, compresses, creates and converts PDFs, all in one place and
without breaking the original layout.

## Why

Most free PDF tools either damage your document (fonts move, layouts shift, quality drops) or
upload your files to someone else's server. The tools that get it right are expensive
subscriptions. PDFoctopus aims to fix that.

## What it promises

1. **Your layout stays intact.** Changes are added on top of the original file instead of
   rebuilding it.
2. **Your files stay with you.** Work happens on your own computer or in your own browser.
3. **Everything in one place.** No more jumping between five different websites.
4. **Free and open source.** Forever.

## The eight arms

| Arm             | What it will do                                                                     |
| --------------- | ----------------------------------------------------------------------------------- |
| ✏️ **Edit**     | Change existing text, add text, images, shapes, highlights, comments and redactions |
| ✍️ **Sign**     | Draw, type or upload a signature, or sign with a digital certificate                |
| 📝 **Forms**    | Fill in, create and flatten PDF forms                                               |
| 🔒 **Password** | Add or remove passwords and set what others are allowed to do                       |
| 🗜️ **Compress** | Make files smaller while keeping them readable                                      |
| 🔄 **Convert**  | Turn PDFs into images, web pages, text or Word documents                            |
| 📄 **Create**   | Make PDFs from scratch, from images, web pages, text or Office files                |
| 📚 **Merge**    | Combine, split, reorder, rotate and extract pages                                   |

## Who it's for

People who work with PDFs every day (contracts, invoices, forms, reports) and want one
dependable tool that respects their documents and their privacy.
